# Fastline store assets

Generated by `node scripts/make-assets.js` (uses `@resvg/resvg-js`). Chosen mark: direction B
(white fasting arc on a faint track, short amber arc for the eating window, on a teal gradient
derived from the accent `#26705F`). Candidates A/B/C and `contact-sheet.png` are in `candidates/`.
To switch direction, change `CHOSEN` in the script and rerun.

| File | Size / format | Store rule it satisfies |
|---|---|---|
| `play-icon-512.png` | 512x512, 32-bit PNG (RGBA), ~95 KB | Google Play hi-res icon: 512x512, PNG, up to 1024 KB. Full-bleed square, no pre-rounded corners or drop shadow (Play applies its own mask and shadow). |
| `play-feature-graphic-1024x500.png` | 1024x500, 24-bit PNG, no alpha, ~80 KB | Play feature graphic: exactly 1024x500, JPEG or 24-bit PNG (no alpha). Mark, name and a four-word tagline only; key content sits in the central area so crops stay safe. |
| `appstore-icon-1024.png` | 1024x1024, RGB PNG, no alpha channel | App Store marketing icon: 1024x1024, no transparency, square corners (Apple rounds them), sRGB. |
| `adaptive-safe-zone-preview.png` | preview only, not for upload | Shows the adaptive icon under circle, squircle and rounded masks with the 66dp-of-108dp safe circle (dashed), plus the monochrome layer. |
| `candidates/*` | previews only | Three directions with 1024 renders and contact sheet at 180/120/60/40 px on light and dark backgrounds. |

In-app assets (in `assets/`): `icon.png` (1024, opaque), `android-icon-foreground.png`
(transparent, mark inside the 66dp safe circle), `android-icon-background.png`,
`android-icon-monochrome.png` (single colour, alpha only), `splash-icon.png` / `splash-icon-dark.png`,
`favicon.png` (48), `favicon-192.png`.

Icon variants (Pro "Themes & app icon"): `assets/icons/{teal,ocean,dusk,sunrise}-icon.png` (1024, opaque) and `*-foreground.png` (transparent Android adaptive foreground), same direction B mark on a per-theme gradient (Teal `#318A75` to `#1B5446`, Ocean `#2F7FBF` to `#173F63`, Dusk `#7468C8` to `#3A2F7A`, Sunrise `#E0683A` to `#8A2F14`). Teal is the store and default icon; the others are alternate launcher icons registered through `expo-alternate-app-icons` in `app.json`. Switching icons works only in a development or production build (not Expo Go or web). The store listing icon is always the default Teal one.

Not verified: the wordmark uses Segoe UI as rendered on the build machine (a system sans, not
embedded); sRGB profile is not embedded in PNGs (untagged PNG is treated as sRGB). Store consoles
were not run, so final acceptance is by the stores' uploaders. No screenshots are included; app
screenshots live in `docs/screenshots/`.
